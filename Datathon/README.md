# 📚 Datathon

Objetivo: Criação de um modelo de machine learning capaz de prever se algum aluno irá entrar em estado de defasagem.
---

## 🛠️ Tecnologias Utilizadas

Ao longo dos projetos, foram utilizadas as seguintes tecnologias:

- Python
- Pandas, NumPy, Scikit-learn, Spark
- Streamlit
- Git & GitHub

---
## ✅ Resultado

Aplicação com uma acuracia de 85,16%, capaz de prever em quais condições um aluno pode apresentar defasagem

https://datathongustavoonaga.streamlit.app/
