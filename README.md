# 📚 Projetos da Pós-Graduação em Data Analytics

Este repositório reúne os projetos desenvolvidos ao longo da pós-graduação,
com foco em **análise de dados, engenharia analítica e machine learning**.

Cada projeto está organizado em sua própria pasta, contendo código, dados
e um README específico com instruções de execução.

---

## 🎓 Sobre a Pós-Graduação

- **Área:** Data Analytics
- **Instituição:** FIAP
- **Objetivo:** Aplicar conceitos práticos de análise de dados, modelagem,
  visualização e machine learning em problemas reais.

---

## 🛠️ Tecnologias Utilizadas

Ao longo dos projetos, foram utilizadas as seguintes tecnologias:

- Python
- SQL
- BigQuery
- Pandas, NumPy, Scikit-learn, Spark
- Streamlit
- Locker
- Git & GitHub
